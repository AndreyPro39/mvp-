# MVP: Анализ B2B-транскриптов через gemma4:31b-cloud

## Что делает
CLI-скрипт читает транскрипты разговоров менеджеров-интегратора Saby,
отправляет их в облачную модель `gemma4:31b-cloud` (через Ollama) и
сохраняет результат в Markdown-таблицы с полями:

- Итог разговора
- Следующий согласованный шаг
- Дата следующего действия
- Потребности клиента
- Основные риски
- Возможные ошибки менеджера
- Что требует внимания руководителя

## Стек
- Python 3.11+
- `ollama` (Python-клиент)
- Модель: **gemma4:31b-cloud** (облачная, через Ollama)
- Без БД, без веб-сервера — CLI + Markdown

## Быстрый старт

### 1. Установка Ollama и вход в аккаунт
```bash
# Установка: https://ollama.com/download
ollama signin                       # обязателен для облачных моделей
ollama list                         # должна быть gemma4:31b-cloud
ollama run gemma4:31b-cloud "тест"  # smoke-тест

результаты output лежат в файле summary_report.txt
